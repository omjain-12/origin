# Claude Code Guidelines for Origin

This project follows a Memory Bank and Modular Agent Architecture.

- **Primary Specifications**: See `AGENTS.md` and `.agents/rules/*.md`.
- **Memory Bank**: Check `.agents/memory/activeContext.md` and `.agents/memory/projectbrief.md` before starting tasks.
- **Project Structure**: Customizations and workflows live in `.agents/`.
- **Quality**: Always write modular, strictly typed code and run tests before finishing.
